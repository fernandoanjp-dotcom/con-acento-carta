Tu carta, siempre al día

Solicita altas, modificaciones y bajas de productos, tanto de las categorías habituales como de Fuera de carta. Puedes agrupar varios cambios en una solicitud y compartir la información con Cartas Digitales para su revisión.

Hasta 50 operaciones por solicitud. Cada una puede ser un alta, una modificación o una baja.

Este formulario prepara una solicitud para enviar, no modifica una carta online ni guarda fotografías en un servidor. La publicación se realizará tras revisión. Los alérgenos deben verificarse con el establecimiento antes de mostrarse al público. Las fechas programadas solo se aplican a «Fuera de carta».

Prepara la entrega

  1. Selecciona la operación para cada producto.
  2. Completa los datos y adjunta las fotos disponibles.
  3. Comparte el ZIP con los cambios y las imágenes a través del canal habitual.

El borrador se guarda solo en este navegador y no incluye las fotografías. Si compartir no está disponible, se descargará el archivo para enviarlo manualmente.
